# Go-live acceptance production

This station connects P33's existing native services. It prepares the client report after the recorded Infrastructure release, obtains the prescribed controlled-document review, delivers the exact reviewed projection, waits for actual human PM and Client sign-off evidence, and verifies native acceptance before linking into release stability follow-up. A delivery receipt establishes document delivery only. Neither a model response nor an agent success establishes business acceptance.

## Configure the dependent actions

The typed, versioned `OPS.factory_go_live_execution` interface controls the original shared allowance, evidence age, bounded activity limits and nominated preparer/publisher. Configure it in the existing project policy screen. The preparer needs current project permissions and actual D05 PM authority; selecting a principal does not appoint a business role. The publisher needs current document publication permission. They may be the same person; separation is not an invented business requirement. Missing publisher configuration leaves useful preparation and review available.

Existing D11 policy selects the controlled template, client recipients, storage and retention. Missing recipients hold publication; they do not prevent otherwise valid client document review. Unknown template/checklist/incident/rollback inputs remain unprovided rather than inferred. The agent can investigate the recorded gaps before all inputs are available.

Actual PM sign-off uses current D05 roles/actions and actual recorded, distinct PM/Client signature evidence for the exact delivered report. The human PM performs that command in the console. There is deliberately no model sign-off tool. External authenticity and legal validity of supplied signatures are separate from the system's recorded evidence checks.

## Carry work through the console

Start go-live acceptance for the existing project and delivery candidate. Select the actual template, deployment checklist, incident reporting and rollback evidence, or record unknown inputs. Continue eligible work to investigate evidence and prepare the controlled client report. The native PMO Lead reviews the exact projection. The configured publisher then delivers it through the selected adapter. Await every exact recipient receipt before presenting human sign-off.

The authorised PM selects the exact delivered report/receipt and two distinct signature records and records the rationale. The agent verifies the native acceptance record and current source, review, recipient and authority contracts. Verified output links to the existing release stability intake with the project and dossier preserved. It does not deploy software or authorise financial release.

## Correct evidence and recover work

Use reviewed source changes to select corrected source records or recover a superseded contract. Earlier reports, reviews and receipts remain immutable. An unresolved original delivery must be reconciled or settled before replacing its sources. A queued publication is awaiting delivery, not awaiting signatures. Unknown delivery requires lookup of the original operation rather than blind retry.

Before actual go-live acceptance, a stopped preparation can receive a fresh explicit instruction after its effects are settled. It retains its lifetime allowance and audit history. Stopping after delivery records follow-up; it cannot retract the delivered report. A revoked publisher holds the original job. Restore current authority and retry that exact job through the native operator command, or settle it without pretending delivery happened.

After actual acceptance, source corrections produce fresh documents, review and receipts. The original go-live event remains unique. A human PM can append a linear evidence reaffirmation only with explicit `D05.decision_action_matrix` schema `decision-actions/v8` action `reaffirm_go_live`, the exact current parent and new distinct unused signature evidence. Older schemas do not acquire that authority. If this policy is undecided, only reaffirmation holds; preparation, review and otherwise authorised publication remain available. Downstream checks follow the current accepted evidence head without resetting the original release clock.
