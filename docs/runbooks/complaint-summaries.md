# B02 complaint summaries by period and scope

Source contract: an authorized reviewer asks for a defined period/scope of permission-filtered complaints, source links, unresolved/reopened evidence, intended audience and review owner. Outputs are a draft with coverage/omission/merge uncertainty and a reviewed summary version. Actual Support ownership and disclosure criteria remain configuration inputs.

The case workbench links to `/cases/<case-uuid>/support/summaries/`. Record private request evidence, then the explicit selected case IDs, aware half-open period, supported membership basis and audience key. Capture works before scope/review configuration. Source cases must be visible Support records in the same tenant/classification. Unauthorized selection is rejected rather than counted as a hidden omission.

Configure B14.summary_scope and B14.summary_review independently. These are supplemental B02 interfaces connected to the existing B14 case/report controls, not new consolidated D groups. Scope governs linked-receipt or recorded-event membership, source/reference budgets, missing-report and merged-case behavior and the allowed metadata fields. Review governs the actual active Support reviewer, configured independence, audience recipients and field subset. No operational values are installed by fixtures or migrations. The normal policy workbench handles validation/activation/supersession/revocation; the summary UI records drafts and displays schemas/status.

Preparation uses the existing LocalSupportReportAdapter and actual current human-reviewed case reports. It does not copy source message bodies, customer_ref/transaction_ref fields, owner names or private model drafts. Optional source references still require configured disclosure agreement. It states selected-case coverage and marks unavailable reports, out-of-period cases, merged-case omissions/marking, unknown clocks and possible unmerged duplicate identities. Duplicate groups contain only selected authorized case IDs; no customer identity fingerprint is exported. UNKNOWN metrics remain null. Period membership is separate from the current reviewed status snapshot; the summary is not a fabricated historical end-of-period report or exhaustive channel claim.
