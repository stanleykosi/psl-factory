# Native publication pilot guard

Engineering implementation, not owner policy or live acceptance. `document.publish` uses `controlled.guard_reserve_publication`, the same preconditions used by the actual reservation service. It checks the exact current version, source preflight, sender permissions, current review authority, template/audience/recipients, retention configuration and prior reservation. Reading readiness creates no publication, job or receipt.

The selected pilot binding takes an exact version ID and case revision for a selected participant. The form shows IDs only and applies document/source Finance observer permissions. Private accepted-Finance metadata retains its separate source-authorised publication interface. A qualified observer cannot supply a missing publisher grant or human review. Finance-bound internal output keeps its native Finance review and does not acquire a new PMO approval gate.

The observation contains source IDs/hashes, current document/review/reservation heads and verified internal receipt state. No titles, projected bodies, financial metrics or recipient payloads are returned. Already-reserved work remains held for source-owned recovery; complete verified receipts, absent receipts and receipt conflicts are distinguished. The guard never retries or republishes.

Native binding arguments use exact bounded integer identities. The forward SQL contract rejects unsupported operations, unselected people, unexpected argument keys/types and foreign source cases. Valid controls against the same contracts accompany negative SQL tests. Applied migrations are immutable; extend the closed registry forward when a new native operation is implemented.

The registry now covers ten declared native operations. Other declared operations remain `NOT_EVALUATED`; complete coverage of one selected contract is not full-product coverage. Engineering review, worker process observation and a current pilot pack do not confer publication or deployment authority.

Actual PostgreSQL, permissions, UI, native AF13 publication, private impact and isolated recovery evidence is recorded in BUILD-TESTS.md. Synthetic fixtures and internal inbox receipts do not establish a real vendor/customer-channel or live pilot result.
