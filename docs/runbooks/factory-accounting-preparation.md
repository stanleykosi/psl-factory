# Accounting preparation and reviewed reports

This production line coordinates existing Finance services. Its tested scope is bounded accounting preparation, not all Finance processes or a live provider evaluation. Source facts and engineering choices are separated in the accounting baseline and acceptance records.

Start from **Work queue → Start work → Prepare management accounts**. Select an authorised workspace and its current controlled trial-balance source. Declare the exact supplemental adjustment inventory; explicitly confirm an empty selection when none applies. A new form key cannot create another allowance for the same accounting scope.

Use **Review accounting execution setup** for versioned limits, information owner, company/BU scope, selected metrics, aggregate template, audience and publisher. These settings do not appoint Finance approvers or override native mapping/formula/review rules. Missing values remain undecided. Earlier independent stages may proceed while only the dependent stage waits.

Continue eligible work to run cited source and calculation investigations and native mapping/allocation/formulas. Reviewers claim the exact source, rule or output subject and record a permitted Finance decision with evidence and reason. Current native authority is checked again; an old claim is insufficient after withdrawal. Decisions entered through the Finance workspace are observed as the same decision.

After output approval, continuation prepares the native aggregate report, reserves its controlled publication and verifies every intended recipient receipt. Agent success is distinct from publication and receipt verification. This flow posts no ledger transaction and records no customer payment. Inspect changed-source and withdrawn-policy items in **Exceptions**; earlier receipts remain historical evidence.

For a returned output, correct the native source/rules as appropriate, then explicitly **Recheck corrected accounting inputs** with the current source and exact adjustment inventory. Original intake, decisions and spent allowance remain in history. A return does not automatically retry the same packet.

For an uncertain publication, use **Check original delivery receipts**. It looks up the original operation and cannot send again. Current authorised operators can reconcile original receipts even after execution-policy withdrawal. Missing or mismatched receipts do not establish success or permission to resend. Resolve original native publication work before changing inputs; use the controlled document recovery interface for its permitted operator dispositions.

The isolated native-browser fixture uses synthetic source/rule decisions and internal inbox delivery. Actual source conventions, mappings, allocation bases, formula/oracle references, qualified reviewers, audiences/recipients, publishers and limits remain owner configuration. No fixture provides live policy, grants, credentials or external integration evidence.
