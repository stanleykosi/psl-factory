# Emergency evidence factory

Start pmo-emergency/v1 from a current native incident-linked Emergency profile. Choose the exact authorization and actual outcome explicitly; null is permitted while people complete those native steps. Configure the typed OPS.factory_emergency_execution component, native D01/D02/D04/D05 policies, report template, current principals and recipient/storage rules. Fixture values are synthetic examples, not business authority.

1. Continue scoped agent investigation. Missing policy or evidence holds only dependent work.
2. Record prescribed native human preauthorization decisions and authorization. This grants no deployment action in the factory.
3. A human records the actual implementation timestamp and evidence. The console shows its timezone, logging time, prior-authorization truth and clock findings separately. Missing/late authorization is retained as such and cannot be repaired by later approval.
4. Record actual post-implementation review and exact review-bound retrospective decisions. Reconcile natively; deferred GLPI evidence must be complete. Historical late status remains an exception.
5. Continue to draft the controlled aggregate retrospective report. A human reviews its exact version, then the factory reserves and delivers only to exact configured recipients. Verification means recorded retrospective plus all report receipts.
6. For returned/stale reports, deliberately correct source selection and redraft. Preserve earlier documents, receipts and spent budget. Resolve pending or unknown effects before replacement. Stop does not undo delivery; reconcile the original publication first. Restart is restricted to settled receipt-free stopped work.

Native historical authority recovery remains a human process in the authority console. It cannot repair authorization missing at implementation, backdate events or waive financial/release controls. Fresh recovery changes report source manifests, so a replacement report needs fresh review; invalid recovery holds current verification without rewriting history.

This increment prepares only a final reconciled retrospective report, not the optional native interim report. Agent work cannot perform preauthorization, attest implementation, approve retrospective decisions or grant ordinary ChangeClosure. Current browser evidence must be rerun after integration.
