# Design reference pages

These are the source files for the three shared design pages on claude.ai. Edit a file here, then republish it to the same link. When you ask Claude to update one, give it the link as well as the file, so it updates that page rather than publishing a new one.

| File | What it is | Live link |
|---|---|---|
| `factory-map.html` | Workflow map: every station, who decides, what agents do | https://claude.ai/artifact/XdvEenuFCmmHisvs6NmJRC |
| `factory-architecture.html` | Architecture for design: layers, objects, 15 step types, states, line handoffs, screens, all 122 processes | https://claude.ai/artifact/PvLfak2iMRsRYh97LnNJLd |
| `approvals-worksheet.html` | Meeting worksheet for PSL: approvals, delegation, deadlines, alerts, roles | https://claude.ai/artifact/GS88TKrtoQ31rN5gScAzCP |

All three are single, self-contained HTML files, so you can open them straight in a browser.

The worksheet's answers live only on the claude.ai page, not in this file. Opened locally, it shows the questions but can't load or save answers.

The pages are design reference, not product source. The factory itself lives in `templates/` and `static/studio.css`.
