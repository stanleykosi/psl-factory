PSL operations factory · design concepts · round 1

Three directions for the same three screens

Each concept shows the work queue, one work item and a decision on a phone, using the same sample content. Compare them section by section; you can keep a section from one concept and combine it with another.

Page A

Control room

Dense, dark and keyboard-fast, with a live schematic of the floor. Built for people who clear a lot of work every day.

Page B

Studio ledger

Light, spacious and editorial, like a well-set project document. Easy to read for anyone, including leadership.

Page C · recommended

Assembly line

Every screen leads with the line the work travels and the facts it has earned, so a draft never looks like an approval.

Sections you can mix: navigation, floor overview, queue tabs, work list · item header, facts strip, stations, agent work, decision panel · on the phone: the question, the detail, the actions.

All names, amounts and dates are sample data. Leave a comment on any section you like or dislike.
