Agent at work: 4 ways to show it

Where an agent is working (here Tola building the planning packet after a won RFP), the panel should show the work happening, not a sentence about it. The same component would be used everywhere: Tola drafting a SOW or weekly report, Chidi drafting an invoice or checking delivery, Zainab matching payroll. Whichever you pick, three rules hold: agent work stays blue; it says which records were used; and it never shows Approve or Send, because only people decide. Movement stops for people who have turned motion down.
