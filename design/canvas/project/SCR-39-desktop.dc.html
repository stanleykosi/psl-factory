PSL standard pricing · v4

CONFIRMED · IN USE
One studio-wide rule used by every new costing. Changing it makes a new version: it must match the worked examples and be confirmed again. Costings already made keep the version they used. One-off changes for a single project are adjustments on that project's costing sheet, not changes here.

Project management share15% of deliveryPricing guide v3, §4
RoundingNearest ₦1,000, half upPricing guide v3, §6
How the total is calculated
  1. engineering = engineering effort × engineering day rate
  2. security = security effort × security day rate
  3. delivery = engineering + security
  4. project management = delivery × 15%
  5. subtotal = delivery + project management
  6. total = subtotal + project adjustment → rounded
