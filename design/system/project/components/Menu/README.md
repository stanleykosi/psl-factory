# Menu

A list of actions that opens from a button (Start work, More actions, the account menu).

- Same surface as the select list: 2px `ink` border and `shadow-pop`.
- Items are 40px or taller with an optional second line; group labels in mono caps; separators in `rule-soft`.
- Item states: default, hover, keyboard-active (blue left edge), disabled with reason, destructive (`signal-ink`, always last, after a separator).
- Esc closes and returns focus to the button that opened it.
