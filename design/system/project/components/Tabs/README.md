# Tabs

Tabs switch between sections of one thing, such as a project's Journey, Milestones, Documents, Money, Registers and Actions. For narrowing a list, use the list toolbar (search and filter), not tabs.

- 44px tall, joined boxes; selected tab fills `ink`. Counts use the count badge; a zero shows "0".
- Labels never wrap. On a phone the tabs become a strip that scrolls sideways and bleeds off the right edge.
- States: default, hover, focus (inset ring), selected.
