# Loading

How a screen or panel says it is waiting, has nothing, or failed.

- **Loading:** three squares and a sentence on what is loading. Old figures are never shown as current while loading; placeholder bars hold the layout for lists.
- **Empty:** a heading and one sentence, plus the action that fills it if there is one ("Nothing needs you right now").
- **Error:** a problem callout saying what failed and a Retry button. Never show a raw error code first.
- **Progress:** for uploads and imports with a known size; mono figures beside it.
- Reduced motion: squares stop pulsing; the words carry the state.
