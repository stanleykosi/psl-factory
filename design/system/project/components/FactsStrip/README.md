# FactsStrip

Six separate facts, each in its own box, so nobody mistakes a draft for an approval. Paid is a Finance fact and always sits apart.

- Labels as the boards write them: DRAFTED, REVIEWED, APPROVED, SENT, RECEIPT (read as "receipt recorded" by screen readers), VERIFIED.
- Earned: `ink` fill with "Earned" and the time ("12 Nov 16:40"). Current: `signal-tint`. Not yet: `surface` with `ink-subtle`, drawn "—" and named "Not yet" for screen readers. Verified: `verified` fill. Unknown: amber, written "Unknown".
- Where a board writes its own words in a box ("Needs you"), the state word stays in the accessible text beside them.
- On phones the six boxes become a 3 × 2 grid.
