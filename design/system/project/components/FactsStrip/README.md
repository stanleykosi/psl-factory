# FactsStrip

Six separate facts, each in its own box, so nobody mistakes a draft for an approval. Paid is a Finance fact and always sits apart.

- Earned: `ink` fill with the date. Current: `signal-tint`. Not yet: `surface` with `ink-subtle`. Verified: `verified` fill. Unknown: amber, written "Unknown".
- On phones the six boxes become a 3 × 2 grid.
