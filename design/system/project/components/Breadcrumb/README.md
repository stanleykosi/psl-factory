# Breadcrumb

A one-line trail above a page title: the section, then the parent record. The current page is the title itself, so it is not repeated as a link.

- Mono 12px caps, `ink-muted`; links in `action` blue. It reads as one line of text, as the boards write it: the " / " separators are plain text between the links, read by screen readers too. A level with no page of its own (a work item's line) is text, not a link.
- Two levels at most (PROJECTS / LAGOON HEALTH). On phones the Back link replaces it.
