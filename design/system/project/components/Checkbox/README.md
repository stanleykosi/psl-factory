# Checkbox

For choosing any number of options, and for confirming a statement ("I confirm this proof is genuine").

- 20px square, 2px `ink` border; checked fills `ink` with a white tick. The whole label is the hit target (at least 36px tall; 44px on phones).
- **Mixed** (indeterminate) is for select-all when only some rows are chosen.
- States: unchecked, hover, focus, checked, mixed, error (required confirmation not ticked), disabled unchecked, disabled checked.
- A second line in `small` explains consequences.
