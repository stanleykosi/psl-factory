# AgentChecklist

Shows an agent doing the work step by step, with the record each step used, so people can follow and trust it and never mistake it for a decision.

- Blue-bordered card: avatar, task, "step n of m", and a WORKING or DONE tag.
- Steps: done (filled blue square with a tick, record named in mono), now (pulsing outlined square, bold), next (numbered grey square), waiting for a person (dashed amber square naming who), stopped (`signal-ink` "!" with the reason).
- Footer: when it started and "Ask Tola". Never Approve, Send or Pay.
- The same checklist sits in the assistant chat above the agent's answer.
- Reduced motion: no pulsing; the WORKING tag and bold step carry the state.
