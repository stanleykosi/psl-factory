# Link

Links go somewhere; buttons do something.

- `psl-link` in reading text: `action` blue, 1px underline, 2px on hover, `action-ink` on hover. Visited links keep the same colour (people revisit work items all day).
- `psl-link--quiet` in lists and tables, where the row already reads as a link: underline only on hover.
- A link to a record the person cannot open is shown as restricted text with a lock, never hidden.
- Never "click here": the link text names the record ("INV-0412", "the signed SOW").
