# Segmented

A row of joined options for a short, single choice: list filters (All, Mine), outcome type (Won, Lost, Pending), period (Week, Month).

- **Every option stays on one line.** Never wrap a label; if the row is too wide it scrolls sideways.
- A count sits in a square mono count badge after the label, never as "· 4" text.
- Chosen option fills `ink` with white text; its badge turns translucent white.
- States: default, hover, focus (inset ring), chosen, disabled option.
- On a phone options are 44px tall and 15px.
- For more than five options, or options that need a sentence each, use radios or a select.
