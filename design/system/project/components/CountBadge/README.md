# CountBadge

A count in a small square: mono 11px, at least 20px wide.

- Grey (`neutral-tint`) on light controls; translucent white on a selected (ink) tab or option.
- Zero shows "0"; it is never hidden, so people can tell "none" from "not loaded".
- The orange badge is only for a count of things that need the person (filters on, items needing me), never decoration.
