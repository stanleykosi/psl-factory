# CountBadge

A count in a small square: mono 11px, at least 20px wide.

- Grey (`neutral-tint`) on light controls; translucent white on a selected (ink) tab or option.
- Zero shows "0"; it is never hidden, so people can tell "none" from "not loaded".
- A count of filters on is an ink badge (`ink` with `on-strong` text), as the boards draw it on the Filter button (D-93).
- The orange badge is only for a count of things that need the person (items needing me), never decoration.
