# Avatar

People get a round avatar with their photo or initials on `neutral-tint`. Agents (Tola, Chidi, Zainab) get their mascot on their own tint, so agent work is never mistaken for a person.

- Sizes 20, 32 (default) and 40px.
- Working: a thin blue ring turns around the agent's avatar while it works (stops when motion is reduced).
- An agent avatar never appears beside an approval, amount or signature.
- The agent chip pairs the avatar with the name for inline mentions.
