# Radio

Choose exactly one option. Plain radios suit short options; **choice cards** suit decisions where each option needs a sentence on what it does.

- Radios are round (the one round control, because people recognise it); 20px with a 2px `ink` border and an `ink` dot when chosen.
- A choice card is a full-width box; the chosen card gets a 4px `ink` border. Its second line says what the choice does and does not do.
- States: unchosen, hover, focus, chosen, error (nothing chosen), disabled with reason.
- Never preselect a decision (a person must choose); preselect only safe defaults.
