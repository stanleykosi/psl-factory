# TextArea

For notes, reasons and descriptions. Same label, hint, error and states as the text field.

- At least 88px tall; grows with content up to 240px, then scrolls. Where a board draws a one-line box ("Anything Chidi should know"), it starts at one line (44px) and grows as people type.
- A reason that is required to Return or Reject says so in the label ("Reason for returning").
- With a limit, the count sits under the box on the right in mono and turns `signal-ink` when over.
