# Disclosure

Hides detail most people do not need, such as an agent's suggestion that was not used or an earlier version.

- Box: summary line in `ink`, bold, with a small triangle that turns when open. Body in `ink-muted` 13px.
- Link: where a board draws the summary as a link ("Preview the invoice", "See his steps"), the summary is a plain `action` link with no box or triangle, and its words can change while open ("Hide the invoice"). Inside a sentence it is an inline link button that shows the detail below the block.
- States: closed, open, focus.
