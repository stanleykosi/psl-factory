# Dialog

A centred box only for confirming something hard to undo (Deactivate an account, Request cancellation). Everything else uses a drawer, so the evidence stays in view.

- Title says the action and the subject ("Deactivate Kunle Ade?"); body says what happens and what does not; footer has Cancel and the action named again.
- Destructive actions use the Reject button; a typed confirmation is not used.
- Esc and Cancel close it; focus starts on Cancel.
