# DecisionPanel

The panel where the right role decides on one exact version, with what is being decided in plain view.

- Orange header "Your decision"; who may decide and whether that is you; amount, basis, recipient, version and what changed; note; Approve, Return, Reject; what approving does not do.
- States: you can decide, someone else decides (read-only, names the role), note required before Return or Reject, submitting, decided (who and when), stale version (asks to reload).
- On phones the actions move to the phone action bar.
