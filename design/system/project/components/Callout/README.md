# Callout

A tinted box with a leading icon above a form or on a work item. No side bar.

- **Info** (blue, "i"): what happens next, how a rule works.
- **Warning** (amber, triangle): something to check, waiting on someone else, sample data.
- **Problem** (orange, triangle, `role="alert"`): blocked or wrong; say how to fix it.
- **Success** (green, tick, `role="status"`): a fact was recorded.
- One or two sentences. Links inside use the callout's text colour, bold.
