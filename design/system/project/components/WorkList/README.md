# WorkList

The main list of work items. Each row: the work title, its line and reference, a mini station bar, the state tag with who it waits on, and its age.

- Whole row is one link to the work item; 1px `rule-soft` between rows.
- Row states: default, hover, focus (inset ring), loading (placeholder bars), empty, error with retry.
- On phones the row stacks: title, then mini bar, then tag and age.
