# FileUpload

For proof (signed SOW, client email, bank statement). Drop or choose a file; it uploads at once and shows its name, size and state.

- Drop zone: dashed `ink` edge; turns solid blue while a file is dragged over.
- Accepted: PDF, PNG, JPG, EML up to 10 MB (say so in the zone).
- File row states: uploading (progress in mono), uploaded (Remove), error (too large or wrong type, with Try again), restricted (can see that proof exists, not open it).
- Proof is required where the factory needs it; the record button explains when it is missing.
